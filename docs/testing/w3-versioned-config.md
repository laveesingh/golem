## Config policy and affected consumers

Canonical `lib/contracts/config.ts` defines ConfigV1 (`schema_version: 1`),
legacy v0 and recursive JsonValue extensions. An absent tag alone migrates v0
in memory. Explicit 0, unknown/future/non-integer tags, malformed JSON and invalid
known field kinds refuse. Reads/default lookup/dry-run never stamp/create config.
Missing file alone permits defaults: dispatch window5, Claude enabledtrue, no Pi
hint/default. Known nullable containers/fields and finite numeric windows stay
valid. Unknown extension JSON, opaque modelMap/testedVersion and custom role
strings remain valid, without Type.Any, coercion or invented semver/role enums.

`lib/golem-config.ts` owns writes; `lib/read-versioned.ts` accepts explicit owner
schemas/migration policy and regular/no-follow read evidence. Request-invalid400,
stored-invalid/unsupported409 and IO500 name the file/recovery but omit raw data.
Save validates input before allocation and stamps1. Captured target-or-absence,
parent and exclusive mode0600 lock/temp/old-byte backup identities fence file
fsync, publication rename, parent fsync, rollback and cleanup. Descriptor-close
failures retain causes; an indeterminate/replaced path retains backup/replacement
evidence rather than gaining ownership from fresh stats. No stale lock reclamation
or EXDEV copy fallback. Existing role/session stores, journal/control mechanisms
are unchanged by the strict role conversion.

JS default role trims/lowercases; shell default stays raw then uses its existing
filename gate. Missing→lead, null/empty→none, custom strings remain accepted.
`config-role-default.ts` resolves source/installed-dist/render helper paths from
caller-relative assets. Assigned session/GOLEM_ROLE paths bypass default lookup.
Missing/error/refused helper exits explicitly. Its direct-execution guard compares
argv realpath, preventing macOS `/tmp` alias from silently skipping validation.

JS waiver files retain ONLY import specifier changes: cli/golem/agent;
model-profiles/worker-manager/role-preset; dashboard substrate/index/roles/tracker-db/
dispatch-queue; MCP index. CC/Pi adapter changes retain ONLY helper inventories.
Owner, generic reader, canonical contract, raw bridge and functional role reader
are strict erasable TS. Immutable debt baseline and accepted package/token
publisher/tools are unchanged.
