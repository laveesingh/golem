# Golem 6.0.1

Patch release for 6.0.0.

## Fixed

- `golem pi` failed to start after upgrading to 6.0.0:
  `Cannot find module './lib/session-role.js'`. The render engine deleted an
  output it had just written when a file's render key changed between syncs
  but its output path did not (the Pi key for `lib/session-role.js` moved from
  `session-role.js` to `session-role.ts`). Orphan pruning now skips a path that
  the current sync still owns. Fresh renders were never affected; only a
  re-sync over an older render was.
- `test/pi-cli.test.mjs` compared the extension version against a hard-coded
  `5.x`; it now reads the package version.

## After upgrading

Run `golem sync --target pi` and `golem sync --target cc`, then update the
installed plugin.
