JITI's filesystem transform cache can survive processes. Disabling JITI_FS_CACHE is a controlled transform-cache experiment, not machine-cold startup. Same-process factory caching is a separate boundary. The probe must report any managed-child cache state it cannot control as unknown.

Successful current Visor patching uses its statically imported host class. Filesystem discovery and which pi belong to fallback paths; no unconditional synchronous-scan startup attribution is established. No QuickJS WASM boot milestone is established.

Verified mechanisms and ownership

  • Native layout visits full content before viewport clipping. Text, Markdown and settled RunGroup raw-child caches still survive frames.
  • Expanded RunGroup child framing and fitLine repeat even when the raw-child cache hits. The bounded optimization extends this cache; it does not replace cascade or theme invalidation.
  • Legacy walking runs on eligible left releases only. Drag, link, chat-boundary, height and empty-registry guards matter. Recursive renders vary with tree structure; there is no fixed “twice per click” rule.
  • Native routing traverses intersecting layout boxes and child row ranges. No constant-time claim or native latency ratio is established.
  • RunGroup owns its chrome, tools, thoughts and existing commentary note regions. Commentary and its nested thought expansion remain independent. Native tools retain their own call/result regions.
  • Standalone managed thinking must acquire a native owner before Visor's legacy subscription can be removed. viewport-mouse stays installed; its public registry and other subscribers stay intact.

Component CPU, layout/paint/diff CPU, PTY first changed-output arrival, and ANSI synchronized-frame completion are different measurements. None measures terminal pixels or scrolling FPS. Scheduling and render coalescing remain visible limits.

Fixture-result selector

ANSI backgrounds/foregrounds, wide characters and combining text are present. Payload line count is not rendered row count; native wrapping and chrome determine the latter.

Approved bounded sequence

  1. S1: commit repeatable fixtures, isolated safety checks, actual-loader probes and this correction. A read-only explorer collects baseline before optimization.
  2. S2: cache complete settled child frames by weak identity, normalized widths, post-render revision and theme. Preserve cascade reconciliation, child theme invalidation, fresh parent chrome/geometry, narrow clipping, detach and live/auxiliary bypass.
  3. S3: add bounds-checked native primary-click handling to managed thoughts through their existing owner. Prove grouped/standalone gestures, then remove only Visor's legacy subscriber and private bridge.
  4. S4: independent review and acceptance across actual loader, fullscreen transcript, mouse regions, streaming, resize, theme, reload and noninteractive paths.

Engineering target, not observed result: reduce expanded 1000-line framing median by at least 50%, subject to correctness. A missed target is reported without widening scope. No blanket no-regression or speedup guarantee.

No speculative bundling, startup/core fix, settings change, shared sync/restart, publication or activation is authorized by this report. Any startup remedy needs a separate measured proposal.
