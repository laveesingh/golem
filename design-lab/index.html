    • One HTML file. Inline CSS and JS, no build, no network, no storage beyond the URL hash.
    • Content uses real Golem entities (workspaces, specs, tasks, docs, agents, teams, review inbox, schedules, model profiles) with invented fixture data.

    • No production file, token, route, or store is touched. Implementing a winner is a separate go.
